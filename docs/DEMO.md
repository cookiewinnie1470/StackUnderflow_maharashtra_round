# Re:Learn demonstration (4–6 minutes)

1. Start on Learn. Open “Try the same-answer demonstration.” Select Learner 1 and analyse their working. The model should identify “Multiplying two negatives,” with the second step as the first algebraic error.
2. Explore the number-line lesson. Toggle either factor's sign; the product changes direction. Return to an attempt.
3. Load Learner 2. The final answer is identical, but the working and explanation differ. Analyse it to see “A minus affects the whole group.” Explore the whole-group sign reversal.
4. Start a three-part check: new problem, explanation plus correction, and a visual representation. Show that feedback appears only after all three. Returning to the lesson ends the unassisted check.
5. Open My Progress. Example sessions must not create personal mastery. For a personal pass, the app records understanding demonstrated and retention pending for at least 24 hours.
6. Open Model Evaluation. Compare the trained model to its answer-only baseline and inspect the confusion matrix and developmental stress-test failures. State that training data is synthetic and the peer pilot is pending.

## Claims to make
- A real CPU-trained logistic regression model uses typed answers, working, and explanations.
- It can distinguish the demonstrated same-answer cases, with an independently implemented algebra checker.
- Interventions are selected from authored, mathematically checked activities; they are not generated by a paid LLM.
- Resolution is an operational assessment state based on three checks, followed by a later retention check—not proof of permanent conceptual change.

## Claims to avoid
- Classroom efficacy, expert review, independent benchmark results, or completed peer sessions.
- General comprehension of all algebra, handwriting, speech, or novel misconception labels.
- Treating the displayed model scores as calibrated confidence about a person's beliefs.
